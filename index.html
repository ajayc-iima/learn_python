Lesson 02

Strings & Text

Text is everywhere — master it

Strings are text values. They're the most-used data type in real programs — every username, tweet, file name, AI response is a string. Python has powerful tools to work with them.

💡
f-strings — the modern way

Instead of "Hello " + name, use f"Hello {name}". The f prefix and {} curly braces automatically insert any variable or expression. This is the standard in 2026.

Lesson 04

Lists, Tuples & Dicts

Storing groups of values — the three essential containers

📋 List [ ]

Ordered, changeable. For sequences: scores, names, items.

🔒 Tuple ( )

Ordered, frozen. For fixed data: coordinates, RGB.

📖 Dict { }

Key→Value pairs. For structured data: student records, config.

🎲 Set { }

Unique values only. Great for removing duplicates.

🛒
Analogy

A list is a shopping list — ordered, you can add/remove items. A dict is a phonebook — you look up a name (key) to get a number (value). A tuple is your date of birth — fixed, never changes.

What does this print?
nums = [10, 20, 30, 40, 50]
print(nums[1:4])
✅ [20, 30, 40] — Slicing [1:4] means "start at index 1, stop BEFORE index 4". Index 1=20, 2=30, 3=40. Index 4 is NOT included. This trips everyone up — the end index is always exclusive.

Lesson 05

Conditionals

Teaching your code to make decisions
📱
Every app uses this

Zomato: if restaurant is open → show order button. Instagram: if follower count > 10,000 → show "Creator" badge. Spotify: if premium → no ads. Same structure, infinite uses.

📌
Indentation is EVERYTHING

Python uses spaces/tabs to group code. The lines inside an if block must be indented (4 spaces or 1 Tab). Missing indentation = SyntaxError. This is different from most other languages.

Loops

Make Python do the repetitive work — so you don't have to
🦥
The Programmer's Creed

Good programmers are cleverly lazy. If you've copy-pasted something more than twice, it belongs in a loop. Loops turn 1000 lines of repeated code into 3 lines.

What does this print?
result = [x for x in range(10) if x % 2 == 0]
print(result)
✅ [0, 2, 4, 6, 8] — range(10) gives 0–9. The condition x % 2 == 0 keeps only even numbers (remainder 0 when divided by 2). Note: 0 is even, and range(10) stops BEFORE 10, so 10 is excluded.

Lesson 07

Functions

Write once, use anywhere — the DRY principle
🍕
The Recipe Analogy

A function is a recipe. You write it once, then call it whenever you need that dish — without rewriting every step. DRY = Don't Repeat Yourself. If the same code appears in 3 places, wrap it in a function.

1

def keyword

Starts the function. Followed by name and parentheses.

2

Parameters

Input slots. Can have defaults: def greet(name, lang="English")

3

return

Sends a value back. Optional — without it, function returns None.

4

Docstring

Description string right after def. Access with help().

What does a function return if it has no return statement?
✅ None — every function in Python returns something. Without a return statement, it implicitly returns None (Python's "nothing"). You can test this: result = print("hi") → print(result) → None.

NumPy & Pandas

The data science power duo — arrays and DataFrames
🧪
Run these in Google Colab

NumPy and Pandas aren't available in this browser editor — they need a full Python environment. Open Google Colab, paste any code example, and run it there. Colab is free and has everything pre-installed.

NumPy gives you fast numerical arrays. Pandas gives you DataFrames — like Excel, but programmable. Together they power almost all data science in Python.

🔢 NumPy Array

Like a list but 100× faster for math. Operations apply to every element at once.

🐼 DataFrame

A table with named columns. Filter, sort, group, merge — everything Excel can do, but in code.

📊 Instant Stats

np.mean(), .std(), .describe() — one line gives you full statistics.

📁 Read Any File

pd.read_csv(), pd.read_excel() — load millions of rows in one line.

numpy_pandas.py — copy & run in Colab 
import numpy as np
import pandas as pd

# ── NumPy: element-wise operations ──
temps = np.array([22.5, 23.1, 22.8, 23.5, 22.9])
print(temps + 273.15)          # adds to EVERY element (not possible with lists!)
print(f"Mean: {np.mean(temps):.2f}")
print(f"Std:  {np.std(temps):.2f}")
print(f"Max:  {np.max(temps):.2f}")
print(temps[temps > 23.0])       # boolean filter

# ── Pandas: DataFrames ──
df = pd.DataFrame({
    "player" : ["Kohli", "Rohit", "Dhoni", "Bumrah"],
    "matches": [269,   255,   350,   90  ],
    "avg"    : [57.3,  48.6,  50.6,  None],
})
print(df)
print(df.describe())                          # stats for all columns
print(df[df["avg"] > 50])                    # filter rows
print(df.nlargest(2, "matches"))            # top 2 by matches

Time Maths

Renaming 200 files by hand: ~25 minutes. Python: 4 seconds. Merging 12 Excel files: ~45 minutes. Python: 8 lines. Emailing 50 students individually: ~90 minutes. Python: 30 seconds. These scripts work right now, in 2026.

Rename 500 photos from IMG_0034.jpg → Trip_001.jpg in seconds. No manual work.

Built-in

pathlib comes with Python — no install needed. It's the modern 2026 way to handle files.

rename_files.py
from pathlib import Path

folder = Path("school_trip_photos")
photos = sorted(folder.glob("*.jpg"))

print(f"Found {len(photos)} photos")

for i, photo in enumerate(photos, 1):
    new_name = folder / f"Trip_{i:03d}.jpg"  # Trip_001, Trip_002...
    photo.rename(new_name)
    print(f"  {photo.name}  →  {new_name.name}")

print("\n✅ All renamed!")

Combine 12 monthly CSV files, clean the data, and export a summary to Excel — all automated.

Install once

pip install pandas openpyxl

merge_files.py
import pandas as pd
from pathlib import Path

# Load all CSVs from a folder in one shot
files = list(Path("marks/").glob("*.csv"))
df    = pd.concat([pd.read_csv(f) for f in files])

# Clean: fix column names, drop duplicates
df.columns = df.columns.str.lower().str.strip()
df         = df.drop_duplicates()

# Fill missing marks with subject median
for col in ["maths", "science", "english"]:
    df[col].fillna(df[col].median(), inplace=True)

# Summary by section
summary = df.groupby("section")[["maths","science"]].mean().round(1)

# Export to Excel with multiple sheets
with pd.ExcelWriter("annual_report.xlsx") as writer:
    df.to_excel(writer, sheet_name="Raw Data",  index=False)
    summary.to_excel(writer, sheet_name="Summary")
print("✅ annual_report.xlsx saved!")

Fetch live data from websites — prices, headlines, scores — without copy-pasting. This is how analysts and journalists get data in 2026.

Install

pip install requests beautifulsoup4 · Always respect a site's terms of service and robots.txt.

web_scrape.py
import requests
from bs4 import BeautifulSoup
import pandas as pd

# books.toscrape.com is a free practice scraping site
url      = "https://books.toscrape.com"
response = requests.get(url, timeout=10)
soup     = BeautifulSoup(response.text, "html.parser")

books = soup.find_all("article", class_="product_pod")
data  = []
for book in books:
    data.append({
        "title"  : book.h3.a["title"],
        "price"  : book.find("p", class_="price_color").text,
        "rating" : book.p["class"][1]
    })

df = pd.DataFrame(data)
df.to_csv("books.csv", index=False)
print(df.head())
print(f"\n✅ Scraped {len(df)} books → books.csv")

Send 100 personalised emails — each with the student's name and specific score. What takes 90 minutes by hand takes Python 30 seconds.

Gmail Setup

Enable 2-step verification → generate an App Password at myaccount.google.com → use that in the script, not your real password.

send_emails.py
import smtplib
from email.mime.text import MIMEText
import pandas as pd

df      = pd.read_csv("students.csv")  # columns: name, email, score
sender  = "[email protected]"
app_pwd = "xxxx xxxx xxxx xxxx"

with smtplib.SMTP_SSL("smtp.gmail.com", 465) as server:
    server.login(sender, app_pwd)
    for _, row in df.iterrows():
        grade = "A 🌟" if row.score>=90 else "B" if row.score>=75 else "C"
        body  = f"""Hi {row['name']},

Score: {row['score']}/100  |  Grade: {grade}

{"Excellent work! 🎉" if row.score >= 90 else "Keep going — you've got this! 💪"}

— Your Teacher"""
        msg            = MIMEText(body)
        msg["Subject"] = f"Result: {row['name']}"
        msg["From"]    = sender
        msg["To"]      = row["email"]
        server.send_message(msg)
        print(f"  ✅ Sent to {row['name']}")

Run scripts automatically every day at a set time — daily reports, price checks, backups — without touching a button.

Install

pip install schedule · For always-on automation use GitHub Actions (free) or a Raspberry Pi.

scheduler.py
import schedule
import time
from datetime import datetime

def daily_report():
    print(f"[{datetime.now():%H:%M}] Generating daily report...")
    # your pandas / email code here

def backup_data():
    import shutil
    shutil.copytree("data/", f"backup_{datetime.now():%Y%m%d}/")
    print("💾 Backup complete")

# Define the schedule
schedule.every().day.at("07:00").do(daily_report)
schedule.every().sunday.at("22:00").do(backup_data)

print("Scheduler started — Ctrl+C to stop")
while True:
    schedule.run_pending()
    time.sleep(60)
